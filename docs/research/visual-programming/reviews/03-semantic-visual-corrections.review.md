# Adversarial review — Bet 03

## Strongest objection

Pointing at a rectangle and copying a property to objects with the same ID is a
small direct-manipulation editor. It is not novel, not intelligent, and not a
reason to replace HTML, JSX, or Engine blocks.

That objection is correct unless the experiment is described narrowly.

## What the experiment can establish

- rendered pixels can be a precise address into a persistent program;
- identity can carry an edit across non-coincident observations;
- an observation predicate can make visual edits local and auditable;
- the directly executable object can be revised without generating UI code.

## What it cannot establish

- that a model can infer the author's intent from an image;
- that the correct propagation scope can be inferred rather than selected;
- that unspecified widths can be synthesized coherently;
- that direct visual editing is faster or produces better UIs than Engine code;
- that the current full scene object is anything other than retained-mode
  markup;
- that accessibility, native behavior, or collaboration are production-ready.

## Falsification criteria

The probe fails even mechanically if it:

1. names the target identity in the authoring operation;
2. edits each observation separately;
3. changes an observation outside the requested phase;
4. loses the correction after encode/decode; or
5. silently edits a point with no stable identity.

## Required verdict wording

“Pixel-addressed semantic propagation passes; authoring superiority and the
AI-specific thesis remain unproven.”
