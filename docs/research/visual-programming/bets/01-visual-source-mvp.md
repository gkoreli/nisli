# Bet 01 — current image generation as the first visual source carrier

## Claim

A current hosted image generator plus a multimodal coding agent is sufficient
to demonstrate the visual-first workflow on one non-trivial Engine screen.

## Why this bet is cheap

It requires no model training and no compiler framework. The image model emits
the visual observations; the coding agent perceives them and emits ordinary
typed blocks; the repository already owns the width and reachability oracle.

## Required evidence

- one behavior contract;
- empty and populated observations at wide and narrow widths;
- one saved visual artifact generated before experiment UI code;
- emitted TypeScript containing no application appearance vocabulary;
- typecheck and `prove()` over both states at five widths;
- a written account of invented semantics and visual information that did not
  survive compilation.

## Kill condition

This carrier is rejected as the actual visual-program representation if it
cannot preserve a persistent editable source or sample a coherent unrequested
observation. Passing screenshot-to-code does not rescue it.

## Expected outcome

The demonstrator should work and the representation should be rejected. That
negative half is valuable: it prevents a polished contact sheet from being
mistaken for the research result.
