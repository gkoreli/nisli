# Worklists

Implementation ledgers, migration checklists, and audit evidence live here so
the repository root and package source directories stay focused on active code
and entry-point documentation.

- [`ui/`](./ui/) — `@nisli/ui` migration and visual-parity worklists.
- [`agn/`](./agn/) — agent-native (ADR 0030.x) design-gate packets.
- [`nextgen/`](./nextgen/) — open strategy scratchpads for the next-generation
  capability bet. Explicitly pre-decision; graduates to ADRs.

Worklists are historical or operational records. Durable architecture belongs
in [`../adr`](../adr), while current package status belongs in the package
README, changelog, or North Star document.
